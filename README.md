# 🧠 NEXUS AI — Intelligent Multi-Agent Data Analyst Team

### 🤖 AI-Powered Data Analytics | CrewAI | Google Gemini | Streamlit

NEXUS AI is an intelligent data analytics application that combines multi-agent AI workflows, interactive visualizations, and automated reporting to transform CSV datasets into meaningful insights and actionable business recommendations.

Built using **CrewAI, Google Gemini API, Python, and Streamlit**, this application brings together three specialized AI agents to analyze dataset statistics, identify business opportunities, and generate structured analytical reports through a modern RGB neon dashboard.

## 🚀 Features

- 🤖 **Multi-Agent AI System:** Three specialized AI agents collaborate through a sequential workflow.
- 📂 **CSV Dataset Upload:** Upload CSV files for analysis.
- 🗃️ **Interactive Data Explorer:** Preview datasets and explore column information.
- 🧪 **Data Quality Analysis:** Identify missing values and duplicate rows.
- 📈 **Interactive Visualizations:** Generate histograms, bar charts, scatter plots, box plots, and correlation heatmaps.
- 🧠 **AI-Powered Insights:** Analyze dataset statistics and identify potential business opportunities.
- 📝 **Automated Report Generation:** Create structured reports with findings and recommendations.
- 📥 **Downloadable Reports:** Export AI-generated reports in Markdown format.
- 💾 **CSV Export:** Download the dataset as a CSV file.
- 🔐 **API Key Configuration:** Configure Google Gemini API access through environment variables.
- 🎨 **RGB Neon Dashboard:** Modern dark-purple UI with neon-purple, cyan, and pink accents.
- ⚠️ **Error Handling:** Handle common API authentication and quota errors.

## 🧠 AI Agent Architecture

### 1. 📊 Senior Data Analyst

- 🔍 Examines dataset structure and statistical information.
- 🧹 Reviews missing values and duplicate records.
- 📉 Identifies numerical and categorical patterns.
- 📋 Reports findings based on the supplied dataset statistics.

### 2. 💡 Business Intelligence Analyst

- 🔎 Reviews the initial analysis.
- 📈 Identifies potential business opportunities and risks.
- 🎯 Develops actionable recommendations.
- ⚖️ Distinguishes observed facts from hypotheses.

### 3. 📝 Executive Report Writer

- 🔗 Combines the previous agents' outputs.
- 📑 Generates a structured business intelligence report.
- 📌 Organizes findings into clear sections.
- ✅ Provides recommendations and suggested follow-up analyses.

### 🔄 Workflow

📂 CSV Upload → 📊 Dataset Profiling → 🤖 Data Analyst → 💡 Business Intelligence Analyst → 📝 Report Writer → 📥 Downloadable Report

## 📊 Dashboard Modules

### 1. 📌 Dataset Overview

Displays essential dataset statistics:

- 📏 Total number of rows.
- 🗂️ Total number of columns.
- ❓ Total number of missing cells.
- 🔁 Total number of duplicate rows.

### 2. 🗃️ Data Explorer

- 👀 Preview the uploaded dataset.
- 🔎 Inspect column data types.
- 📋 Review non-null, missing, and unique values.
- 💾 Download the dataset as a CSV file.

### 3. 🧪 Data Quality

- 📉 Visualize missing values by column.
- 🔁 Check duplicate records.
- 🛡️ Review basic dataset quality indicators.

### 4. 📈 Visual Analytics

Choose from the following interactive chart types:

- 📊 **Histogram:** Explore numerical distributions.
- 📉 **Bar Chart:** Compare category frequencies.
- 🔵 **Scatter Plot:** Explore relationships between numerical variables.
- 📦 **Box Plot:** Examine distributions and potential outliers.
- 🌡️ **Correlation Heatmap:** Visualize correlations between numerical columns.

📌 Available charts depend on the uploaded dataset's column types.

### 5. 🤖 AI Analyst Team

- 💬 Enter a question or analysis objective.
- 🔍 Review the generated dataset profile.
- 🚀 Run the three-agent AI workflow.
- 📝 View the final business intelligence report.
- 📥 Download the report as a Markdown file.

## 🔐 API Configuration and Limitations

- 🔑 A valid Google Gemini API key is required to run the AI analysis.
- 📊 API availability, rate limits, and usage quotas depend on your Google AI account and selected model.
- ⚠️ AI analysis may fail if the API quota is exhausted or access is denied.
- 📂 The current application accepts CSV files up to **20 MB**.
- 📏 The application supports datasets with up to **200,000 rows and 100 columns**.
- ✅ AI-generated recommendations should be validated against the business context and source data.
- 🧮 The AI workflow uses supplied dataset statistics rather than sending the entire raw dataset to the agents.
- 🚧 Database integration and real-time data streaming are not currently implemented.
